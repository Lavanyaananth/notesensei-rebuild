# Notesensei

Notesensei is a note-taking application built from scratch using react.

The goal of this project is to build the application while understanding the architecture, state management, APIs, and deployment process rather than blindly copying code.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS

```bash
npm install
npm run dev
```

The application will run locally using the Vite development server.
